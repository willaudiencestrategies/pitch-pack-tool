# Workshop 2 Implementation Design — v1.2

**Date:** 2026-01-29
**Status:** Approved
**Source:** E Studio Workshop 2 (27 January 2026)

---

## Overview

Major architectural refactor based on client workshop feedback. Transforms tool from single linear flow into explicit two-gate model separating brief assessment from creative brief development.

---

## Key Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Approach | Full redesign with placeholders | Build structure now, slot in E Studio materials later |
| Gate structure | Explicit two-phase UI | Matches mental model, clear transition point |
| Research Stimuli | Optional appendix | Workshop said deprioritise; keep available but outside main flow |
| Context capture | Combined upload screen | Lowest friction, "therapy couch" approach |
| Background scoring | Stub for later | Add hooks now, build storage/UI in v1.3 |
| Creative Tenets | Prompt-then-generate | User control, explicit dependency on prior work |
| Brand Alignment | Simple dropdown + checkbox | CPs know their brand; value is in downstream flagging |
| "What Good Looks Like" | Build UI with placeholder content | Shows feature, gives E Studio template to fill |

---

## Architecture: Two-Gate Model

### Gate 1: Brief Interrogation

**Purpose:** Assess what the seller provided
**Mindset:** "What do we have to work with?"

| Order | Section | Changes |
|-------|---------|---------|
| 1 | Objective | Remove quantified targets, add coherence checking |
| 2 | Budget | Force production budget question, require dollar amount |
| 3 | Audience | Force prioritisation (1 primary, max 2 secondary) |
| 4 | Creative Task | Standardise as template to confirm/amend |

### Gate 2: Creative Brief Development

**Purpose:** Build the creative brief with CP input
**Mindset:** "Now let's create what's missing"

| Order | Section | Changes |
|-------|---------|---------|
| 5 | Brand Alignment | NEW — Expedia/Hotels.com/Vrbo + DG match |
| 6 | Audience Insights | Renamed from Human Truths, bold-first, max 3 |
| 7 | Creative Tenets | REBUILT as generative step |
| 8 | Media Context | Renamed from Media Strategy, CP input only |

### Optional Appendix

- Research Stimuli (available but outside main flow)

---

## Step Flow

```
Upload + "Tell Me More" (combined screen)
        ↓
   Gate 1 Triage (4 sections only)
        ↓
   Gate 1 Section Review (iterate until satisfied)
        ↓
   ─── TRANSITION: "Now let's build the creative brief" ───
        ↓
   Gate 2: Brand Alignment (select brand + DG match)
        ↓
   Gate 2: Audience deep-dive (personas, prioritisation)
        ↓
   Gate 2: Audience Insights (generate bold→safe, select max 3)
        ↓
   Gate 2: Creative Tenets (prompt: "Generate based on your work?")
        ↓
   Gate 2: Media Context (CP input, not AI-generated)
        ↓
   Output (with optional Research Stimuli appendix)
```

## Gate 1 Section Details

### Objective

- Remove quantified targets from assessment (ROAs, conversion % don't influence creative)
- Add coherence checking:
  - Does objective align with budget?
  - Does objective align with timeframe?
  - Are multiple objectives conflated?
- Force prioritisation: Primary vs secondary objectives
- Stub coherence parameters with sensible defaults; E Studio refines later

### Budget

- Add mandatory question: "What is the production budget?"
- Explain: production budget ≠ total campaign budget (typically ~10%)
- Require dollar amount, not percentage
- Total budget = context; production budget = what creatives work with

### Audience

- Force prioritisation: ONE primary, max TWO secondary
- Primary audience gets full persona treatment
- Secondary audiences = segment names only
- Add Expedia audience overlay when brand criteria materials arrive

### Creative Task

- Standardise as template rather than generating each time
- Default: "Put forward 1-3 concepts with creative overview, insight used, example executions, and campaign tenets"
- User confirms or amends
- Remove detailed format questions

## Gate 2 Section Details

### Brand Alignment (NEW)

**Purpose:** Select brand, capture DG match status

**UI:**
- Dropdown: Expedia / Hotels.com / Vrbo
- Checkbox: "Is there DG match/co-investment?"
- Info text explaining each brand's core audience (placeholder until materials arrive)

**Data model:**
```typescript
interface BrandAlignment {
  brand: 'expedia' | 'hotels_com' | 'vrbo' | null;
  hasDGMatch: boolean;
  brandAudience: string;
}
```

**Downstream:** Flags inconsistencies in Audience section

### Audience Insights (renamed from Human Truths)

- Rename throughout UI and code
- Reorder options: bold first, safe last
- Limit selection to maximum 3
- If multiple audiences, keep insights separate per audience

### Creative Tenets (REBUILT)

**Fundamental change:** Generative, not extractive

**Flow:**
1. User arrives at section
2. Show summary: "You've confirmed: [Audience], [3 insights]"
3. Prompt: "Generate Creative Tenets based on this work?"
4. If yes → Generate tenets laddering from insights
5. Present as "thought starters" not constraints
6. User can edit, regenerate, or proceed

### Media Context (renamed from Media Strategy)

- Rename throughout
- Remove detailed strategy/plan generation
- CP input only: media direction notes, DG match status, key channels
- Not AI-generated

- Enlarge Edit button
- Add Undo button (revert last change)

- Expandable panel per section
- Placeholder content for v1.2

### Traffic Light Calibration

- Tighten criteria in triage prompt
- Reserve GREEN for truly strong work
- Most sections should be AMBER on first pass
