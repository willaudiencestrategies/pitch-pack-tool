# v1.2 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Transform the Pitch Pack Tool from 8-section linear flow into explicit two-gate architecture with new Brand Alignment section, renamed sections, rebuilt Creative Tenets as generative step, and UX improvements.

**Architecture:** Two-gate model: Gate 1 assesses 4 sections from seller brief (Objective, Budget, Audience, Creative Task), Gate 2 builds 4 sections with CP input (Brand Alignment, Audience Insights, Creative Tenets, Media Context). Research Stimuli moves to optional appendix.

**Tech Stack:** Next.js 14, TypeScript, React, Tailwind CSS, Anthropic Claude API

${additionalContext ? `- Additional Context: ${additionalContext}` : ''}

Generate 3-5 Creative Tenets as thought-starters. Return JSON with 'intro' (1-2 sentences connecting tenets to audience work) and 'tenets' (array of 3-5 tenet strings, each 10-25 words).

Return ONLY valid JSON, no markdown.`;

    const response = await callClaude(prompt);

    // Parse response
    let parsed: { intro: string; tenets: string[] };
    try {
      // Try to extract JSON from response
      const jsonMatch = response.match(/\{[\s\S]*\}/);
      if (jsonMatch) {
        parsed = JSON.parse(jsonMatch[0]);
      } else {
        throw new Error('No JSON found in response');
      }
    } catch {
      // Fallback structure
      parsed = {
        intro: 'Based on your confirmed audience and insights:',
        tenets: [response],
      };
    }

    // Defensive: ensure tenets is an array
    const tenets = Array.isArray(parsed.tenets) ? parsed.tenets : [parsed.tenets || response];

    return NextResponse.json({
      intro: parsed.intro || '',
      tenets: tenets.slice(0, 5), // Max 5
    } as CreativeTenetsResponse);
  } catch (error) {
    console.error('Creative tenets generation error:', error);
    return NextResponse.json(
      { error: 'Failed to generate creative tenets' },
      { status: 500 }
    );
  }
}
